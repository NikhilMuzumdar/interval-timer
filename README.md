# 40/20 Interval Timer

A browser timer that repeats 40 seconds of work and 20 seconds of rest until you pause it.

Live site: https://nikhilmuzumdar.github.io/interval-timer/

- Full screen button (or press F)
- Space starts and pauses, R resets
- Bluetooth earbuds and media keys can pause and resume it after you press Start once
- Work and rest lengths can be changed on the page
